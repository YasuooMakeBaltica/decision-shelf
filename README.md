# Decision Shelf

A private, browser-only journal for recording important decisions, then reviewing the outcome later.

## Run it

No build step or dependencies are needed. Open `index.html` in a modern browser, or publish this folder using GitHub Pages.

## Features

- Add decisions with context, reasoning, category, and a review date
- Filter decisions that are due for review, unfolding, or closed
- Record an outcome and reflection
- Light/dark mode
